Commands
- flutter doctor — Checks your local environment and displays a report of installed dependencies, tools, and missing configuration items needed for Flutter development.
- flutter analyze — Performs static analysis on your code to detect syntax errors, missing imports, unused variables, and linting rule violations without running the app.
- flutter run — Compiles, builds, and launches your Flutter application on a connected physical device, emulator, or web browser with hot reload enabled.
- flutter pub get — Downloads and installs all external packages and dependencies listed in your project's pubspec.yaml file into your local project environment.
- flutter pub upgrade — Upgrades all specified package dependencies in your pubspec.yaml file to their latest compatible versions.
- flutter pub add <package> — Automatically adds the specified package to your pubspec.yaml file and downloads it for immediate use in your app.
- flutter pub remove <package> — Removes the specified package dependency from your pubspec.yaml file and deletes its cached reference from the project.
- flutter build <target> — Compiles your app into a release-ready binary bundle or installer for a specific target platform like Android (apk/appbundle), iOS (ipa), Web, or Desktop.
- flutter clean — Deletes the temporary build directory, clearing out cached build artifacts and compiled assets to resolve stale build issues.
- flutter create <app_name> — Scaffolds a new Flutter project template with all required directory structures, configuration files, and starter code.
- flutter test — Executes unit, widget, and integration tests located in your test/ directory to verify your app's logic and user interface behavior.
- flutter devices — Lists all connected physical mobile devices, running emulators, browsers, and desktop platforms currently available for app deployment.
- flutter emulators — Displays all configured Android and iOS virtual device images installed on your machine and allows you to launch them directly.
- flutter logs — Streams real-time log output, stack traces, and console print statements from your running Flutter application on a device.
- flutter upgrade — Downloads and updates your installed Flutter SDK framework and Dart tools to the latest release on your current git channel.
- flutter channel — Lists available Flutter SDK release channels (stable, beta, master) and switches your current active SDK track.
- flutter config — Configures global Flutter SDK settings such as enabling support for specific platforms like Web, Linux, Windows, or macOS builds.
- flutter attach — Attaches the Flutter debugging tools and hot reload engine to an already running instance of your app on a device or emulator.
